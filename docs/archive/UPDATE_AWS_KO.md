## 적용 전

새 ColorPop_Standalone.zip을 서버의 /home/ubuntu/ColorPop_Standalone.zip으로 업로드하세요.
아래 명령은 기존 컨테이너 이름이 colorpop이고 앱이 /app에 설치된 배포판용입니다.
현재 컨테이너의 포트·네트워크·환경변수·볼륨을 유지하기 위해 컨테이너는 삭제하지 않습니다.
새 이미지를 빌드하고 기존 컨테이너의 앱 파일을 교체한 뒤 다시 시작합니다.
이 작업은 이 수정본의 소스 수정과 빌드를 마친 후 만들어진 public/을 사용하므로 npm 설치가 필요하지 않습니다.

```bash
cd /home/ubuntu
unzip -o ColorPop_Standalone.zip -d poprush-update
cd /home/ubuntu/poprush-update/ColorPop_Standalone
sudo docker ps -a --filter name=^/colorpop$
sudo docker inspect colorpop --format '{{range .Mounts}}{{println .Name .Source "->" .Destination}}{{end}}'
```

위 출력에서 기존 데이터 저장 위치(/data 등)를 확인합니다. 실행 중인 컨테이너가 다르면 이름을 맞춰야 합니다.

## 이미지 빌드 및 기존 컨테이너 업데이트

아래 블록은 중간 명령이 실패하면 뒤 명령을 실행하지 않습니다. 게임 서비스가 잠시 중단됩니다.
앱 폴더를 덮어쓰며 계정 DB와 볼륨은 삭제하지 않습니다. 기존 프록시(Nginx/Caddy) 설정은 건드리지 않습니다.

```bash
(
set -e
cd /home/ubuntu/poprush-update/ColorPop_Standalone
sudo docker inspect colorpop >/dev/null
sudo docker build -t colorpop:latest .
sudo docker stop colorpop
sudo docker cp public/. colorpop:/app/public
for module_file in ./*.mjs; do
  sudo docker cp "$module_file" "colorpop:/app/$(basename "$module_file")"
done
sudo docker cp migrations/. colorpop:/app/migrations
sudo docker start colorpop
sudo docker logs --tail 30 colorpop
)
```

`COLORPOP_READY 3000` 로그를 확인하세요. 실패했다면 먼저 오류를 확인하고, 필요한 경우 `sudo docker start colorpop`으로 재시작합니다.
새 이미지도 빌드했으므로 이후 컨테이너를 재생성할 때에는 colorpop:latest와 기존 실행 설정 및 데이터 볼륨을 사용하세요.

## 브라우저 확인

1. 기존 게임 주소에 접속하고 Ctrl+F5로 새로고침합니다.
2. 첫 방문에서는 화면을 클릭하거나 '눌러서 음악 재생'을 눌러 소리를 허용합니다.
3. 접속 시 음악 자동 재생을 시도하는지 확인합니다. 차단되면 첫 클릭으로 시작합니다.
4. 자유 플레이나 AI전을 시작하고, 남은 시간 30초에 같은 곡이 끊기지 않고 1.25배속이 되는지 확인합니다.
5. 음악 끄기와 볼륨 설정이 유지되는지 확인합니다.
6. 기존 계정과 랭킹이 그대로인지 확인합니다.

'마지막 30초'는 재생 중인 곡의 속도만 바꿉니다. 음악 끄기와 볼륨은 유지됩니다.
게임 종료 후에도 음악은 이어지고 재생속도는 1배속으로 복귀합니다.
블록을 제거하면 해당 위치에 콤보 숫자가 표시됩니다. 보너스 단계 상승 시 음성 안내가 나옵니다. 음성 미리 듣기로 기기 지원을 확인하세요.
숨겨진 탭에서는 일시 정지합니다.

새 경기 시작(아레나 카운트다운 종료 / 자유 플레이 새 게임) 시 현재 곡을 0초부터 재생합니다. 동일 경기 메뉴 재진입은 초기화하지 않습니다.

블록 제거 효과음: public/sounds/block-pop.mp3 (사용자 제공 MP3 원본). 대전과 자유 플레이에 적용하며 최대 6개 재생 슬롯을 사용합니다.

콤보 보너스: public/sounds/combo-bonus.mp3 (사용자 제공 MP3 원본). 보너스 단계 상승 시 재생하며 기존 합성 음성과 축하음은 제거했습니다.

## 콤보 점수 규칙 (버전 28)
2초 이내 연속 제거 시 콤보가 이어집니다. 기본 점수는 제거 블록 수² × 10입니다.
| 콤보 | 추가 보너스 | 총배율 |
|---|---|---|
|1–9|0%|1배|
|10–19|10%|1.1배|
|20–39|20%|1.2배|
|40–59|35%|1.35배|
|60–89|50%|1.5배|
|90–119|75%|1.75배|
|120–149|100%|2배|
|150–174|150%|2.5배|
|175–199|200%|3배|
|200 이상|250%|3.5배|
해당 콤보에 도달한 제거 동작부터 적용하며, 단계 상승 시 사용자 제공 콤보 효과음이 나옵니다.
기존 기록은 다시 계산하지 않습니다. 업데이트 전 진행 중인 경기는 종료한 뒤 적용하세요.

## 운영자 테스트 (버전 29)

```bash
read -r -p "운영자 게임 로그인 아이디: " poprush_admin_user
sudo docker exec colorpop node /app/set-test-admin.mjs "$poprush_admin_user"
```
해당 계정으로 로그인하고 새로고침하면 운영자 테스트 버튼이 보입니다. 다른 계정과 게스트는 서버에서 차단합니다. 테스트는 독립된 점수·효과음 미리보기이며 실제 경기를 조작하거나 기록을 저장하지 않습니다. 지정 정보는 DATABASE_PATH의 DB와 같은 디렉터리에 보관됩니다.

## admin 운영자 계정 설정 (버전 30)
서버 업데이트 후 아래 명령으로 비밀번호를 입력하세요. 비밀번호는 ZIP에 저장되지 않습니다. admin 계정이 없으면 생성하고, 있으면 비밀번호를 변경하며 기존 로그인 세션을 해제합니다. admin 계정만 운영자 테스트 탭이 표시됩니다.
```bash
read -r -s -p "admin 비밀번호: " poprush_admin_password
echo
printf '%s' "$poprush_admin_password" | sudo docker exec -i colorpop node /app/setup-admin.mjs
unset poprush_admin_password
```
설정 후 admin으로 로그인하세요. 운영자 테스트 탭에서 콤보 단계, 배율, 효과음을 확인할 수 있으며 기록은 저장하지 않습니다.

## 운영자 UI 미리보기 (버전 31)
운영자 탭에 10×10 테스트 블록판과 게임과 동일한 콤보 팝업을 추가했습니다. 각 단계 버튼 또는 블록을 누르면 선택한 콤보·보너스·점수·효과음을 확인합니다. 2초 게이지는 시각 미리보기만 하며 콤보를 초기화하지 않습니다. 실제 경기 이벤트와 테스트 이벤트는 분리합니다. 기존 admin 계정은 다시 설정할 필요가 없습니다.

## 공지사항·버그&건의사항 (버전 31)
맨 앞 공지사항은 운영자 admin만 작성, 맨 뒤 버그&건의사항은 로그인 계정이 작성합니다. 읽기는 공개이며 글은 DB에 저장합니다. 0003 마이그레이션이 시작 시 자동 적용됩니다. 기존 계정과 랭킹은 유지합니다. 운영자 UI 테스트 블록판도 포함합니다.

## 게시글 수정·삭제 (버전 32)
운영자는 모든 글, 일반 로그인 계정은 본인 글만 수정·삭제합니다. 게시글을 펼치면 권한에 맞는 버튼이 표시됩니다. 서버가 로그인 계정 ID와 실제 작성자 ID를 비교하며 작성자 정보는 변경하지 않습니다. 수정 표시와 동시 편집 충돌 검사를 추가했습니다. 삭제 시 확인창이 표시됩니다. 0004 마이그레이션은 기존 글을 유지하며 편집 정보 열만 추가합니다.

## 모바일 입력 보완 (버전 33)
두 번째 손가락 터치도 입력하며, 게임판 위 스크롤·확대 제스처를 막았습니다. 게임판 밖에서는 스크롤 가능합니다. 터치의 마우스 호버 계산을 제거하고 모바일에서 블록 호버 축소를 해제했습니다. 터치 이후 호환 클릭 중복을 방지하며, 효과음 초기화 예외가 게임 입력과 대전 전송을 중단하지 않도록 처리했습니다. 실제 단말의 체감 반응과 회선 지연은 추가 확인이 필요합니다.

## 결과창 → 대전방 복귀 (버전 34)
결과창 확인과 경기 종료 후 대기실 버튼은 방 탈퇴 대신 기존 대전방으로 복귀합니다. 방 코드·설정·AI는 유지하며 온라인 참가자가 결과 확인을 마치면 다음 경기를 시작할 수 있습니다. 복귀하지 않은 접속 종료 참가자는 마지막 확인 후 30초 경과 시 대기 대상에서 제외합니다. 다음 경기 기록은 별도 경기 ID로 저장해 같은 방 재경기를 중복 기록으로 무시하지 않습니다. 방을 나가려면 대기실의 나가기를 사용합니다.

기존 참가자가 종료된 방 코드를 재입력하면 종료 경기 화면 대신 대기실로 복귀합니다. 외부 사용자는 결과 확인 중인 종료 방에 들어갈 수 없으며 대기실 전환 후 입장할 수 있습니다.

## 모바일 상단 메뉴 (버전 35)
700px 이하에서는 탭을 한 줄 좌우 스크롤로 표시합니다. 선택 탭은 옅은 보라색 글자와 가는 밑줄로 강조하며 탭 변경·화면 회전 시 선택 항목을 화면 안으로 이동합니다. PC 메뉴와 공지·건의·운영자 권한은 유지합니다. 결과 대전방 복귀와 종료방 코드 재입장 수정도 포함합니다.

## 음량바 수정 (버전 36)
일반 입력창의 패딩·테두리가 range에 적용되던 부분을 초기화했습니다. 음량 0~100%에서 손잡이가 가용 트랙의 양 끝까지 이동하며 채움 색과 숫자를 같은 값으로 표시합니다. 모바일 드래그 중 input 이벤트로 즉시 반영하고 손잡이는 작은 원형으로 통일했습니다. 페이지 음량바 조절에 적용되며 기기 하드웨어 볼륨과 별개입니다.

## 실제 소리 음량 수정 (버전 37)
음악·블록 효과음·콤보 보너스·운영자 테스트 소리를 공통 Web Audio GainNode로 연결했습니다. iOS에서 HTMLMediaElement.volume 변경이 반영되지 않는 문제에 대응합니다. 바를 움직이면 공통 출력 게인이 즉시 변경되어 재생 중인 소리에도 적용됩니다. 0%는 출력 게인 0, 100%는 원본 게인 1입니다. 최초 사용자 입력으로 오디오 컨텍스트를 활성화하며 기기 하드웨어 볼륨은 별도입니다.

## 모바일 전체 탭 표시 (버전 38)
모바일 메뉴를 가로 스크롤 대신 동일 너비 3열 격자로 변경했습니다. 모든 메뉴가 화면 안에 표시되며 운영자 테스트 탭도 권한이 있으면 같은 격자에 추가됩니다. 선택탭 자동 가로 이동은 제거했습니다. 700px 초과 PC 메뉴는 유지합니다.

## Android 호환·전체 메뉴·화면 꺼짐 이탈 (버전 39)
구형 Android 브라우저를 위해 Chrome 70 / Safari 12 / Firefox 78을 대상으로 JS·CSS를 빌드합니다. 이는 해당 기기 실물 실행 보증이 아닙니다. 모바일·태블릿 메뉴는 3열 격자로 표시하며 가로 스크롤 스타일을 제거했습니다. 화면이 숨겨지거나 페이지를 닫으면 모바일은 방에서 나갑니다. 화면 잠금과 앱 전환·탭 전환은 같은 이탈 처리입니다. 이탈 후 늦게 온 서버 응답으로 방이 다시 열리는 것도 막습니다. heartbeat가 끊긴 추적 참가자는 서버에서 약 20초 이후 정리되며 대기실 방장도 포함합니다. 아래쪽 v39로 실제 적용 여부를 확인할 수 있습니다. /version.json은 캐시하지 않습니다.

## 게임 화면 공간 정리 (버전 40)
사용자 요청으로 모바일·터치 태블릿 메뉴를 한 줄 가로 스크롤로 되돌렸습니다. 게임판 위 COMBO 대기·상태·2초 게이지·누적 보너스 박스를 제거했습니다. 클릭 위치 콤보 숫자, 보너스 점수 계산, 효과음은 유지하며 운영자 미리보기에서도 고정 콤보 바를 제거했습니다. Android 호환 빌드와 화면 숨김 시 방 이탈은 유지합니다.

## 오클릭 0초·운영자 랭킹 제외 (버전 41)
대전방 생성과 자유 플레이에 0초(시간 차감 없음)를 추가했습니다. 오클릭 시 콤보 초기화는 유지합니다. 서버도 0~10초를 허용하며 기본값은 기존 1초입니다. admin 계정의 실제 계정 ID를 기준으로 일반 TOP 100 및 모든 난이도 AI 랭킹에서 제외합니다. 기존 결과 데이터와 개인 기록은 삭제하지 않습니다.

## 랭킹 안내 정리·부하 테스트 도구 (버전 42)
일반·AI 랭킹의 운영자 제외 안내 문구만 제거했습니다. 서버의 admin 순위 제외 규칙은 유지합니다. Node.js 24용 loadtest.mjs와 LOAD_TEST_KO.md를 포함합니다. 별도 PC에서 10→25→50→100명 단계별로 본인 서버 API 부하를 측정할 수 있습니다. 배포만으로 부하 테스트가 실행되지는 않습니다.

## 랭킹 페이지 나누기 (버전 43)
일반·AI 전 난이도 TOP100을 한 페이지10명씩 총10페이지로 표시합니다. 이전·다음·페이지번호로 이동하고 실제 순위11~20,91~100을 유지합니다. AI 난이도를 바꾸면1페이지로 돌아갑니다. 데이터가 없는 순위는 기존 빈자리 안내로 표시합니다. 서버 정렬·운영자제외·점수 계산은 유지하며 DB 변경은 없습니다.

## PC 창 전환 종료 (버전 44)
PC에서도 탭 전환·최소화·다른 프로그램으로 포커스 이동 시 대전방을 나갑니다. 경기 중이면 기권 처리하고 대기실이면 참가칸에서 나옵니다. 창 포커스 이탈은150ms 후 재확인해 즉시 복귀한 일시 이벤트를 줄입니다. 자유 플레이도 창 전환 시 종료하고 결과를 표시합니다. 참가자 아님·방 없음 응답 시 오래된 방 화면과 캐시를 정리합니다.
