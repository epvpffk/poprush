v58 모바일·태블릿 이탈 기권 및 운영자 레벨 조정 확장

모바일·태블릿은 화면 숨김, 다른 브라우저 탭·앱 이동, 페이지 종료 및 freeze 이벤트에 반응합니다.
터치 기기의 포커스 이탈은 지연 타이머 없이 처리합니다. PC는 기존 150ms 확인을 유지합니다.
이탈 요청은 beacon과 keepalive로 전송하며 미확인 요청은 복귀·재접속 시 재전송합니다.
서버는 첫 heartbeat 수신 전부터 참가자의 연결을 추적합니다. 통신이 끊기면 약 20초 뒤 기권 판정 대상이 되며 조회/정리 시 반영됩니다.
게임 내부 상단 메뉴로 이동할 때도 진행 중 대전을 먼저 기권하고 이동합니다.
운영자 테스트: XP +10,000, 레벨 +10/−10, 레벨 초기화 버튼을 추가합니다.
레벨 초기화는 확인 후 운영자 본인의 레벨 1, 누적 XP 0으로 실제 저장합니다. 경기 전적은 유지합니다.
레벨 +10/−10은 1~200 안에서 목표 레벨 시작 XP로 이동합니다.
상대 퍼즐 표시 및 기존 연결 풀·DB 작업자·JSON 최적화는 유지합니다.
적용: sudo -n python3 apply-update.py
