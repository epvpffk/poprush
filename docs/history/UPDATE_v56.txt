v56 실시간 매칭 결과 복귀 및 헤더 정리

실시간 매칭은 경기 결과 확인 후 대기실을 만들지 않고 아레나 메인으로 돌아갑니다.
결과창과 경기 종료 버튼은 '아레나로 돌아가기'로 표시합니다.
다시 매칭할 때 종료되었거나 본인이 기권한 이전 경기를 재사용하지 않습니다.
이전 화면에서 이미 만들어진 매칭 대기실도 새 검색에서 재사용하지 않습니다.
일반 초대방은 기존처럼 결과 확인 후 같은 방 대기실로 돌아갑니다.
경험치와 경기 기록은 결과 확인 전 저장되며 기존 중복 지급 방지를 유지합니다.
헤더에서 레벨 배지 앞의 동그란 프로필 아이콘을 제거합니다. 숫자 배경색 레벨 배지는 유지합니다.
운영자 테스트 탭: 본인 계정 레벨 +1/−1 및 XP +1/+10/+100/+1000 버튼을 추가합니다.
레벨 변경과 XP 지급은 실제 DB에 저장됩니다. 서버 권한 확인으로 일반 계정 요청을 차단합니다.
레벨 이동은 목표 레벨의 시작 XP로 이동하며 1~200 범위를 벗어나지 않습니다.
