# 음악과 효과음

## 배경음악

Kevin MacLeod / incompetech.com의 아래 음원이 포함되어 있습니다.

- Pixel Peeker Polka — slower
- Pixel Peeker Polka — faster
- Bit Quest
- Bit Quest urgent: 원본에서 1.25배 템포로 만든 마지막 30초용 파생 파일

기존 크레딧은 Creative Commons Attribution 4.0으로 표기되어 있습니다. 원래 표기는 `MUSIC_CREDITS.txt`, `source/public/music/CREDITS.txt`, `public/music/CREDITS.txt`에 보관했습니다. 게임 안의 음악 정보에서도 크레딧을 표시합니다.

## 효과음

`block-pop.mp3`, `combo-bonus.mp3`는 사용자가 제공한 파일입니다. 기존 크레딧에는 원본 파일명만 있고 저작자·라이선스가 제공되지 않았다고 기록되어 있습니다. 이 저장소 정리 과정에서 새로운 이용 허락이나 라이선스를 확인한 것은 아닙니다. 해당 기록은 `source/public/sounds/CREDITS.txt`와 `public/sounds/CREDITS.txt`에 그대로 보관했습니다.

제3자 음원의 권리는 해당 권리자에게 있으며 소스 저장소에 별도의 오픈소스 라이선스를 부여하지 않았습니다.
